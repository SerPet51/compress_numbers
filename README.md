# compress_numbers

Функция на Python, которая удаляет подряд идущие дубликаты из массива.

```python
compress_numbers([1, 1, 2, 2, 3])  # [1, 2, 3]
compress_numbers([0, 0, 1, 1, 0])  # [0, 1, 0]
```

## Файлы

- `compress_numbers.py` — функция
- `test_compress.py` — автотесты

## Использование

```python
from compress_numbers import compress_numbers

compress_numbers([4, 4, 4, 5])  # [4, 5]
```

- Возвращает новый список, исходный не изменяется.
- Принимает любую последовательность (список, кортеж).
- Сложность: O(n) по времени и памяти.

## Запуск тестов

```bash
pip install pytest
pytest test_compress.py
```

Вместе с doctest-примерами из функции:

```bash
pytest --doctest-modules compress_numbers.py test_compress.py
```

## Что покрыто тестами

Примеры из задания, пустой массив, один элемент, массив без дубликатов, все элементы одинаковые, дубликаты в начале/середине/конце, неподряд идущие повторы, отрицательные числа, float, большие числа, отсутствие мутации входных данных, кортеж на входе, большой вход (300 000 элементов), идемпотентность.
